# 🚚 Перенос NexusTG на другой ПК

Полная инструкция за ~20 минут. Старый ПК = «А», новый = «Б».

---

## Часть 1 — на старом ПК (А)

### 1.1 Останови работающие копии
В окнах PowerShell с `run.ps1` и `web.ps1` нажми **Ctrl+C** и дождись «Остановка по Ctrl+C…». Не закрывай окна сразу — пусть SQLite корректно допишет данные.

Если процессов уже нет, или зависли:
```powershell
Get-Process python -ErrorAction SilentlyContinue | Stop-Process -Force
```

### 1.2 Создай миграционный архив
В папке проекта (`C:\Users\User\ClaudeC\aichatpom\`) запусти:
```powershell
.\migrate.ps1
```
Скрипт:
- остановит зависшие python-процессы
- сделает SQLite `WAL_CHECKPOINT(TRUNCATE)` — сольёт `.wal`-журнал в основной `.db`
- упакует весь проект (без `.venv`, кешей и старых бэкапов) в `NexusTG_migrate_YYYYMMDD_HHMM.zip`
- напечатает напоминание о шагах

Архив примерно 200-400 МБ (зависит от объёма БД).

### 1.3 Перенос файла
Скопируй `NexusTG_migrate_*.zip` на ПК Б любым способом: флешка, OneDrive, переслать самой себе в Telegram (Saved Messages), SSH/SCP — что удобно.

⚠️ **Архив содержит твою Telegram-сессию** — относись как к паролю. Не оставляй на чужих компьютерах, не отправляй в открытые чаты.

### 1.4 НЕ ЗАПУСКАЙ старую копию на А
Пока проверяешь работу на Б — оставь А выключенным. Если запустишь параллельно — Telegram отзовёт сессию у обоих. После убеждения что Б работает, можно удалить папку на А (или оставить как бэкап в архиве, но не стартовать).

## Часть 2 — на новом ПК (Б)

### 2.1 Установи зависимости
Открой PowerShell от обычного пользователя (не admin).

**Python 3.12+** (если не стоит):
```powershell
winget install Python.Python.3.12
```
Перезапусти PowerShell после установки.

**uv** (менеджер окружения):
```powershell
winget install astral-sh.uv
```
Альтернативно: `irm https://astral.sh/uv/install.ps1 | iex`

Проверь:
```powershell
python --version    # 3.12.x или новее
uv --version        # 0.4 или новее
```

### 2.2 Распакуй архив
Выбери папку для проекта. Рекомендую:
```
C:\Users\<Имя>\NexusTG\
```

Распакуй `NexusTG_migrate_*.zip` сюда. Через проводник: правый клик → «Извлечь всё».

Куда **нельзя**:
- `C:\Program Files\...` (требует admin, UAC будет мешать)
- Папки в OneDrive / Яндекс.Диск / Dropbox (синхронизация портит SQLite)
- Сетевые диски, USB-флешки (WAL не работает на сетевых ФС)
- Пути с пробелами или кириллицей

### 2.3 Установи окружение
В новой папке:
```powershell
cd C:\Users\<Имя>\NexusTG
uv sync
```
Это создаст `.venv` и поставит все зависимости. Занимает 1-3 минуты.

Если `uv` не получается — fallback на pip:
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-windows.txt
```

### 2.4 Проверь конфиги
Открой `.env` (через Notepad или VS Code) — там должны быть твои ключи:
```
TG_API_ID=...
TG_API_HASH=...
XAI_API_KEY=...
TG_BOT_TOKEN=...
TG_MY_ID=...
```
И `config.toml` — настройки приложения. Обычно ничего менять не нужно.

### 2.5 Первый запуск
```powershell
.\setup.ps1
```
Скрипт спросит про сессию:
- **«Use existing session? [Y/n]»** → жми Enter (или `Y`). Сессия из старого ПК будет использована, повторный логин в Telegram не нужен.
- Если ответил `n` или сессия повреждена — попросит ввести телефон и код заново.

### 2.6 Запусти конвейер
```powershell
.\run.ps1
```
Жди:
```
[NexusTG] Подключаюсь к Telegram...
Я: id=585416677 username=@alina_dubinets
Архивных чатов: 28 — пропускаем их.
Listener запущен, жду сообщений
```

Открой ВТОРОЕ окно PowerShell в той же папке и:
```powershell
.\web.ps1
```

Перейди в браузер на **http://127.0.0.1:8000/** — увидишь NexusTG с твоими задачами.

### 2.7 Проверь что всё на месте
- Инбокс показывает задачи (фильтр «Упоминания» по умолчанию)
- В `/health` — счётчики совпадают со старым ПК
- В `/topics` — твои темы
- В `/rules` — твои правила «Алина-режим»
- В Telegram-боте отправь `/start` — он должен ответить

## Часть 3 — что делать со старым ПК

### Вариант 1 — оставить как «холодный бэкап»
Просто не запускай `run.ps1` на А. Папка лежит, если что-то с Б случится — можно вернуться.

### Вариант 2 — почистить полностью
Удали папку `C:\Users\User\ClaudeC\aichatpom\` целиком. Перед удалением сделай `.\migrate.ps1` ещё раз и сохрани зип в долгий бэкап (другой диск, облако).

⚠️ Не запускай старую копию параллельно с новой никогда. Telegram отзовёт обе сессии и придётся заново вводить SMS + 2FA.

## Возможные проблемы и решения

| Проблема | Решение |
|---|---|
| `uv: command not found` после установки | Перезапусти PowerShell |
| `Python is not installed` | `winget install Python.Python.3.12` |
| `database is locked` при первом запуске | Убей все python-процессы: `Get-Process python | Stop-Process -Force` |
| Не присылает код в TG (после `n` на вопрос про сессию) | См. раздел «Первый запуск» в `GUIDE.md` |
| 429 от Gemini | Открой https://aistudio.google.com — баланс/billing проверь |
| Веб открывается, но инбокс пустой | Подожди 30-60 сек пока listener подцепится. Если не появится — проверь `/health` |
| Бот не отвечает | Проверь что `TG_BOT_TOKEN` и `TG_MY_ID` подцепились (видны в `.env`) |
| Старая сессия не работает («unauthorized») | На А запусти на минуту → подтверди что жива, потом снова перенеси |

Точно те же шаги, только направление меняется. Главное правило одно: **одновременно жива только одна копия**.
