# 📋 Отчёт о проекте NexusTG

## Что сделано

**Локальный агрегатор Telegram-задач** для Алины. Собирает из ~40 чатов ЛС, упоминания и ответы на её сообщения, классифицирует через LLM, показывает в веб-инбоксе + шлёт в собственный TG-бот.

5 фаз + дополнения:
1. **Ingest** — Telethon-listener + 30-дневный backfill. Захватил 3500+ задач.
2. **Classifier** — Gemini 2.5 Flash, авто-таксономия (140+ тем на русском), urgency 1-5 + importance 1-5.
3. **Web** — FastAPI + HTMX + Pico.css. Инбокс / Поиск (FTS5) / Темы / Дайджест / Health / Карточка сообщения с ±5 контекстом.
4. **Actions** — Готово / Snooze (1ч / завтра / понедельник / своё) / Архив + Windows toast + self-ping в Saved Messages, всё gated 10:00-18:30 Europe/Minsk.
5. **Pack** — управление чатами (allow/block), отчёты + CSV-экспорт, reclassify, ⭐ примеры для дообучения, Telegram-бот с инлайн-кнопками, страница «Выполненные».

**Доп**: Алина-режим (правила свободным текстом), фильтр архивных и ботов, шорткаты (j/k/e/s/a/o/t/?), 4 цветовые схемы, тёмная/светлая тема, аватар+ник в шапке, анимированные кнопки и вкладки, neural-сеть на фоне, видео-логотип, ребрендинг с aichatpom на NexusTG.

**2 июня:**
- Listener теперь ре-синкает диалоги и перечитывает `archived/processing_off` каждые 5 минут (`telegram_listener.py:chats_refresher`). Лечит пропуски упоминаний из недавно раз-архивированных чатов.
- `get_reply_message()` исключение логируется (`log.warning`) вместо тихого `pass` — видим, если reply-to-me потерялся из-за временной ошибки Telegram.

**Финальные допы** (31 мая):
- **Шаблоны** (`/templates`) — CRUD заготовок текста.
- **Быстрый ответ** в карточке сообщения — POST в `outbox`, фоновый `outbox_sender` отправляет через user-сессию как reply_to. Развязывает веб и run.ps1 (Telethon-сессия одна, делить нельзя).
- **Выполненные** (`/done`) — архив помеченных done с возможностью вернуть.
- **Migration toolkit**: `migrate.ps1` (stop + WAL checkpoint + zip), `requirements-windows.txt` (pip fallback), smart `setup.ps1` (распознаёт битую сессию).
- `MIGRATE.md` — пошаговая инструкция переноса.

## Оптимизации

- **Pre-filter тривиала** — короткие фразы/эмодзи/приветствия идут в БД без вызова LLM (-25-40% стоимости)
- **Батчинг 5 сообщений/запрос** — system-prompt амортизирован (-70% input-токенов)
- **Параллелизм 6** — х5 скорость классификации
- **Фильтр архивных + ботов + не-processing чатов** — экономия токенов на шуме

Итог: $1.24 за классификацию 3253 сообщений → потом ~$0.005/день в steady-state.

## Важные ошибки в процессе

- **Кеш Win PowerShell 5.1** ломался на UTF-8 кириллице в `.ps1` → переписал на ASCII.
- **xAI Grok** оказался без кредитов и с устаревшими моделями → миграция на Gemini.
- **Gemini 3.1 Pro Preview** имеет жёсткий RPM-лимит → переключили на 2.5 Flash.
- **`database is locked`** при параллельных процессах → добавили `PRAGMA busy_timeout=30000`.
- **2FA в Telegram** при первом логине — пользователь не понял что нужен облачный пароль, не SMS → доработал инструкцию.
- **HTMX не находил target** для строк инбокса — id содержал `:` (двоеточие интерпретируется как CSS-псевдокласс) → заменили на `_` через Jinja-фильтр.
- **Counter в инбоксе** не пересчитывался при `hx-swap="delete"` → добавили JS-хук на `htmx:afterSwap`.
- **TG deep-link** для групп не работал (`tg://openmessage?chat_id=` неверный формат) → перешли на `tg://privatepost?channel=` для Desktop и `https://t.me/c/` для бота.
- **Наш собственный бот** засирал инбокс своими уведомлениями → добавили фильтр `sender.bot == True`.
